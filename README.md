# Eklavya

Parent mobile app for Gurukull — React Native + Ant Design Mobile.

API base: `https://app.gurukull.in/api`

## Run

```sh
npm install
npm start
npm run android
```

## Login

Use a parent mobile number registered in Gurukull (field is mobile, not email).

Demo:
- Mobile: `9887403108`
- Password: `password`

## Stack

Mirrors `gurukull-teacher-ant`:
- React Native 0.83
- `@ant-design/react-native`
- AsyncStorage session + selected child
